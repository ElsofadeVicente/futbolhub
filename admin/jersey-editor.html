¿Cómo funciona esto?
  • Cada equipo tiene una lista de "nombres clave" y un objeto kit (colores + patrón).
  • El juego busca el nombre del equipo dentro de esas claves (sin acentos, en mayúsculas) para elegir la camiseta.
  • Añade equipos con el formulario de la izquierda, o pega/edita el JSON completo directamente.
  • Cuando termines, pulsa "Descargar kits.json" y sustituye el archivo en en-el-once/data/kits.json.
