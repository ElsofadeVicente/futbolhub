Aquí tienes una guía de referencia rápida:

CONFIGURACIÓN INICIAL (solo la primera vez en una carpeta)
git init
git remote add origin https://github.com/usuario/repositorio.git
git fetch origin

SUBIR CAMBIOS
git add -A                          # añadir todos los cambios
git add archivo.js                  # o solo un archivo concreto
git commit -m "descripción"
git push origin nombre-rama

FORZAR SUBIDA (sobreescribe lo que hay en GitHub)
git push origin nombre-rama --force

CAMBIAR DE RAMA
git checkout nombre-rama            # cambiar a una rama existente
git checkout -b nueva-rama          # crear rama nueva y cambiarte a ella

VER ESTADO
git status                          # qué archivos han cambiado
git branch -a                       # qué ramas hay (locales y remotas)
git log --oneline                   # historial de commits

BORRAR ARCHIVOS DEL REPO (pero no de tu ordenador)
git rm --cached archivo.js
git rm -r --cached carpeta/
git commit -m "eliminar del repo"
git push origin nombre-rama

DESHACER CAMBIOS
git restore archivo.js              # descartar cambios sin guardar
git reset HEAD~1                    # deshacer el último commit (conserva los archivos)

DESCARGAR CAMBIOS DE GITHUB
git pull origin nombre-rama

FLUJO HABITUAL DEL DÍA A DÍA
git add -A
git commit -m "lo que has hecho"
git push origin nombre-rama
